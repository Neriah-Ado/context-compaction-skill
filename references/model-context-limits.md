# 模型上下文窗口与触发阈值（通用）

> 用途：确定"70% 触发线"的绝对值。各模型数值以**官方文档为准**；本表仅收录已核实条目，未列出的模型一律走 §保守规则。

## 保守规则（未列出模型的默认处理）

1. **默认按 16K 窗口估算**（触发线 ≈11K tokens）——宁可早压缩，不可溢出。
2. **token 估算**：中文 ≈1.5 字符/token，英文/代码 ≈4 字符/token；不确定时按字符数 ÷2 保守折算。
3. **长上下文衰减**：接近窗口上限时模型对早期信息召回精度下降（所有长上下文模型的通病），因此 70% 是质量红线而非容量红线——重要决策应尽早写入快照，不要等压缩时才抢救。
4. **小窗口模型**（8K/16K）建议每完成一个子任务就增量更新快照，而非等触发线。

### 扩展方法

接入其他模型（Claude / GPT / GLM / DeepSeek 等）时：查阅该模型官方文档的 context window 字段 → 按 70% 计算触发线 → 在上表追加一节并注明核实日期。**不要凭记忆填表**——窗口规格随版本变动频繁。
